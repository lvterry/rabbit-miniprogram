## 上线验收

1. 确认自动构建的仓库/分支为本项目待发布代码，应用目录与构建上下文为 `server/`。
2. 部署期间暂停旧服务的业务写入；首次启动会迁移既有数据，旧版本继续写旧表会造成新旧数据不同步。
3. 确认构建与数据库初始化成功；健康检查通过后，首页和「我的」加载正常。
4. 创建课程与学员（或使用自己指定的测试档案），添加课时及实收金额，检查学员余额、记录和报表。
5. 添加预约，确认首页及学员详情均可进入同一课次；改期、备注、取消扣次/不扣次、恢复、完成和撤销均有历史。
6. 验证余额不足会阻止扣次，切换微信用户无法读取他人的资料，重新编译后数据仍在。
7. 提交反馈及修改展示姓名，重新打开确认保存结果；用真机走完整操作链路。

本地验证：接口与前端联调测试、独立 MariaDB 上的 MySQL 适配器集成测试、微信 WXML/WXSS 编译和模拟器错误状态检查。线上服务已更新并通过真实云托管接口及模拟器检查；真机完整业务操作链路待验收。
