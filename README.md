# 小兔排课 · 交互原型

微信小程序原生代码制作的本地交互原型。课程、学员、收入、反馈和登录状态都使用本地模拟数据。

## 打开

用微信开发者工具打开本目录即可。项目配置已包含小程序 AppID。打开后编译首页，在「今日」里点选课程体验课程详情与操作。

## 可体验的流程

- 今日课程及近期课程 → 课程详情
- 改期、编辑课程备注
- 取消课程（消耗或不消耗课时）、恢复课程
- 标记完成、撤销完成
- 操作历史与状态变化
- 学员活跃/未活跃列表与学员详情
- 编辑学员资料、添加课时与查看记录
- 为学员添加预约，预约会出现在首页课程列表
- 「我的」页面的访客与演示账号状态
- 我的课程：编辑、新增课程，查看课程学员名单并进入学员详情
- 财务报表：总收入、按课程占比和按月份收入
- 关于页面与意见反馈
- 课程海报预览和小程序转发

所有变更保存在微信开发者工具的本地存储中。微信登录只调用小程序登录入口并切换演示账号，不会连接后端或同步到云端；转发使用小程序原生转发卡片。需要重置时可清除开发者工具中的本地存储并重新编译。当前数据和状态处理仅用于确认交互流程，不代表最终的数据结构或接口协议。
